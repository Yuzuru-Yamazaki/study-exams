# G9 MATH · SETS · PAPER 01

## A — Multiple Choice (1 mark each)

1. Which one of the following is a **well-defined** set?
   (a) Collection of beautiful girls in your class (b) The set of vowel letters of the English alphabet
   (c) Collection of hardworking teachers in a school (d) Collection of good basketball players
2. Given A = {2, 4, 6, 8, 10}, which statement is true?  (a) 2 ∉ A (b) 7 ∈ A (c) 4 ∈ A (d) 6 ∉ A
3. The set A = {1, 3, 5, 7, 9, …} in set-builder form is
   (a) {x | x ∈ ℕ, x is even} (b) {x | x ∈ ℕ, x is odd} (c) {x | x ∈ ℕ, x > 9} (d) {x | x ∈ ℤ, x > 0}
4. Which one of the following is an **empty set**?
   (a) {x | x ∈ ℕ and 5 < x < 6} (b) {0} (c) {x | x ∈ ℕ and x ≤ 1} (d) {2}
5. The set of all even natural numbers is a (a) finite set (b) empty set (c) infinite set (d) universal set
6. If A = {1, 2, 3}, the number of **proper subsets** of A is (a) 8 (b) 7 (c) 6 (d) 3
7. A = {0, 1, 3, 5, 7} and B = {1, 2, 3, 4, 6, 7}. Then A ∪ B =
   (a) {0, 1, 3, 5, 7} (b) {1, 3, 7} (c) {0, 1, 2, 3, 4, 5, 6, 7} (d) {2, 4, 6}
8. Using the sets in Q7, A ∩ B = (a) {0, 2, 4, 6} (b) {1, 3, 7} (c) {0, 1, 2, 3, 4, 5, 6, 7} (d) ∅
9. Given U = {1, 2, 3, 4, 5} and A = {2, 4}, then A′ = (a) {1, 3, 5} (b) {2, 4} (c) {1, 2, 3, 4, 5} (d) ∅
10. If B = {3, 4} and A = {1, 2, 3, 4}, then (a) B is a proper subset of A (b) A ⊂ B (c) B ⊃ A (d) A = B
11. Two sets A and B are **disjoint** if (a) A = B (b) A ⊂ B (c) A ∩ B = ∅ (d) A ∪ B = ∅
12. Sets A and B are **equal** if (a) n(A) = n(B) (b) A ⊂ B only
    (c) every element of A is in B and every element of B is in A (d) A ∩ B = ∅
13. A = {1, 2, 3, 4}, B = {3, 4, 5, 6}. Then A \ B = (a) {3, 4} (b) {1, 2} (c) {5, 6} (d) {1, 2, 3, 4, 5, 6}
14. If A = {1, 2, 3} and B = {3, 4, 5}, then A Δ B = (a) {3} (b) {1, 2, 4, 5} (c) {1, 2} (d) {1, 2, 3, 4, 5}
15. n(A) = 20, n(B) = 28 and n(A ∪ B) = 36. Then n(A ∩ B) = (a) 48 (b) 12 (c) 8 (d) 20
16. The number of subsets of a set having 6 elements is (a) 12 (b) 32 (c) 64 (d) 128
17. In a Venn diagram, the region representing A ∪ B is shaded by (a) shading both circles completely
    (b) shading only the overlapping region (c) shading only one circle (d) shading the region outside both circles
18. If X = {2, 4, 6, 8} and Y = {1, 4, 9}, then n(X) + n(Y) = (a) 7 (b) 8 (c) 9 (d) 16
19. If n(A) = 5, then the number of elements in the **power set** of A is (a) 10 (b) 25 (c) 32 (d) 16
20. For any set A, the complement of its complement, (A′)′, is (a) A (b) A′ (c) ∅ (d) U

## B — Short Answer (2 marks each)

21. List **all** subsets of the set {a, b, c}.

22. Write {x | x ∈ ℕ and 4 < x < 9} using the complete listing (roster) method.

23. Give the set-builder form of D = {4, 8, 12, 16, …}.

24. A = {0, 2, 4, 6} and B = {1, 2, 3, 5, 6}. Find (i) A ∩ B and (ii) A Δ B.

## C — Problems (3 marks each, show working)

25. In a class of 60 students, 35 like football, 25 like basketball and 12 like both.
    (a) How many like exactly one sport? (b) How many like neither? (c) Sketch the Venn diagram.

26. A = {2, 4, 6, 8, 10}, B = {1, 2, 3, 4, 5}.
    Find (a) A ∪ B, (b) A ∩ B, (c) A \ B, (d) B \ A,
    (e) verify n(A ∪ B) = n(A) + n(B) − n(A ∩ B).

27. Let U = {1, 2, 3, …, 12}, A = {1, 3, 5, 7, 9}, B = {2, 3, 5, 7, 11}.
    Write down and shade: (a) A′, (b) A ∩ B, (c) A ∪ B, (d) (A ∪ B)′.
