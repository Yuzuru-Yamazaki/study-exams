# G11 MATH · RELATIONS & FUNCTIONS · SET 01

## 1.1 Relations

1. A **relation** from set A to set B is defined as
   (a) Only a subset of A (b) A subset of A × B (the Cartesian product) (c) The union of A and B (d) Any set containing both a and B
2. If A = {2, 4, 6}, which ordered pair belongs to the relation ≤ ⊂ A × A?  (a) (6, 4) (b) (4, 6) (c) (6, 2) (d) (4, 2)
3. The **domain** of a relation R from A to B is the set of (a) first elements of the ordered pairs of R (b) second elements of the ordered pairs of R (c) elements in B never used by R (d) all elements of A × B
4. For R = {(1, a), (2, b), (3, c)}, the range of R is (a) {1, 2, 3} (b) {a, b, c} (c) {1, a} (d) {a, b}
5. R = {(x, y) : y = x + 1, x ∈ {1, 2, 3}}. The range of R is (a) {2, 3, 4} (b) {1, 2, 3} (c) {0, 1, 2} (d) {1, 2, 3, 4}
6. A relation R is *reflexive* on A if for all x ∈ A (a) (x, y) ∈ R implies (y, x) ∈ R (b) (x, x) ∈ R (c) (x, x) ∉ R (d) (x, y) and (y, z) in R imply (x, z) ∈ R
7. A relation R is *symmetric* if (a) (x, x) ∈ R for all x (b) (x, y) ∈ R implies (y, x) ∈ R (c) (x, y), (y, z) ∈ R imply (x, z) ∈ R (d) R = ∅
8. An *equivalence relation* is one that is (a) reflexive and symmetric only (b) reflexive, symmetric and transitive (c) reflexive and transitive only (d) symmetric and transitive only

## 1.2 & 1.3 Functions, Domain and Range

9. A *function* f : A → B is a relation in which (a) every element of A has one image in B (b) some elements of A have two images (c) every element of B is an image (d) A = B
10. Which of the following relations R from A to B is a function?  (a) {(1,a),(1,b),(2,c)} (b) {(1,a),(2,b),(3,c)} (c) {(1,a),(2,a),(2,b)} (d) {(1,a),(1,b),(1,c)}
11. The domain of f(x) = √(x−2) is (a) {x : x ≥ 2} (b) {x : x > 2} (c) ℝ (d) {x : x ≤ 2}
12. The range of f(x) = x² is (a) ℝ (b) {y : y ≥ 0} (c) {y : y > 0} (d) {y : y ≤ 0}
13. The domain of f(x) = 1/(x−3) is (a) ℝ (b) {x : x ≠ 3} (c) {x : x > 3} (d) {x : x < 3}
14. If f(x) = 3x − 2, then f(4) = (a) 12 (b) 10 (c) 14 (d) 6
15. If f(x) = x² + 1, then f(−3) = (a) −8 (b) −10 (c) 10 (d) 7
16. The range of f(x) = 2x + 1 over domain {1, 2, 3} is (a) {3, 5, 7} (b) {1, 2, 3} (c) {0, 2, 4} (d) {2, 4, 6}
17. If f(x) = 4x − 3 and g(x) = 2x + 5, then (f + g)(x) = (a) 6x + 2 (b) 6x − 2 (c) 2x − 8 (d) 6x + 8
18. With f(x) = 4x − 3 and g(x) = 2x + 5, (f − g)(x) = (a) 2x − 8 (b) 6x + 2 (c) 2x + 8 (d) 8x + 2
19. With f and g as above, (fg)(x) = (a) 8x² + 14x − 15 (b) 8x² − 14x + 15 (c) 8x² + 26x − 15 (d) 6x² + 2x
20. (f ∘ g)(x) means (a) g(f(x)) (b) f(g(x)) (c) f(x) · g(x) (d) f(x) + g(x)
21. If f(x) = 2x and g(x) = x + 3, then (f ∘ g)(x) = (a) 2x + 6 (b) 2x + 3 (c) (x + 3)(2x) (d) 2(x²) + 3
22. If f(x) = 2x and g(x) = x + 3, then (g ∘ f)(x) = (a) 2x + 6 (b) 2x + 3 (c) 2x² + 6 (d) 2 + 3x

## 1.4 Types of Functions

23. A function f : A → B is *one-to-one* (injective) if (a) f(a₁) = f(a₂) implies a₁ = a₂ (b) every element of B is an image (c) f is constant (d) both A and B are finite
24. A function f : A → B is *onto* (surjective) if (a) f is one-to-one (b) every element of B is the image of some element of A (c) no two elements share an image (d) f is injective and injective only
25. A function that is both one-to-one and onto is called (a) a constant function (b) an identity function (c) a bijection (d) a partial function
26. Which of the following is a constant function?  (a) f(x) = x (b) f(x) = 5 (c) f(x) = 2x + 1 (d) f(x) = x²
27. f(x) = x² over ℝ is an example of a function that is (a) one-to-one and onto (b) one-to-one only (c) onto only (d) neither one-to-one nor onto
28. f(x) = 2x + 3 over ℝ is a function that is (a) one-to-one and onto (b) one-to-one but not onto (c) onto but not one-to-one (d) neither
29. An *identity function* is defined by (a) f(x) = 0 (b) f(x) = x (c) f(x) = 1 (d) f(x) = x²

## 1.5 Inverse of a Function

31. The inverse of f(x) = x/3 − 4 is (a) f⁻¹(x) = 3x + 12 (b) f⁻¹(x) = 3x − 12 (c) f⁻¹(x) = (x + 4)/3 (d) f⁻¹(x) = x/3 + 4
32. A function f has an inverse if and only if f is (a) onto (b) one-to-one (bijective for f : A → A of finite sets) (c) constant (d) even
33. If f(3) = 7, then f⁻¹(7) = (a) 7 (b) 3 (c) −3 (d) 21
34. The graphs of y = f(x) and y = f⁻¹(x) are symmetric about the line (a) y = 0 (b) x = 0 (c) y = x (d) y = −x
35. If f(x) = 3x − 9 and f⁻¹(x) = (x + 9)/3, then (f ∘ f⁻¹)(5) = (a) 0 (b) 5 (c) 15 (d) 24
